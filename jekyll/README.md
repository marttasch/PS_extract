# Usage in Development
## Build Jekyll Docker Image
- clone this repository
- edit the `Dockerfile` to include any additional dependencies you may need
- build the docker image, replacing `marttasch/jekyll` with your desired image name
  - ``docker build -t marttasch/jekyll .``
- you now have a docker image named `marttasch/jekyll` that you can use to build your jekyll site

## Run Jekyll Docker Server
### Create Jekyll Site Directory
- create a new directory for your jekyll site
  - OPT 1: copy an existing jekyll site into this directory
  - OPT 2: create a new jekyll site in this directory using: 
  ``docker run --rm -v $(pwd)/jekyll:/srv/jekyll marttasch/jekyll jekyll new .``

### Set Up Docker Compose
- rename container-name to your desired container name
- rename image to the name of your docker image
- set the volumes to point to your jekyll site directory
- FIRST RUN: uncomment the `command` line with `bundle install` to install dependencies
    - dependencies will be stored in a Docker volume named `jekyll-bundle`
- SUBSEQUENT RUNS: use the command without `bundle install` to start the jekyll server faster with the installed dependencies

### Run Docker Container
- use the command: `docker-compose up` to start the jekyll
  - you can now access your jekyll site at `http://localhost:4000`

# Usage in Production
For production, you can use the same Docker image to build your jekyll site, but you need to use a web server to serve the static files generated by Jekyll, because the Jekyll server is not suitable for production use.
The `compose-prod.yml` is set up to use the `nginx` web server to serve the static files generated by Jekyll.

## Build Jekyll Docker Image
- see instructions in Development section

## Run Jekyll Docker Build
### Create Jekyll Site Directory
- see instructions in Development section

### Set Up Docker Compose
- see instructions in Development section

### Set Up Nginx Configuration
- edit the `nginx.conf` file
  - change the `server_name` to your desired domain name
  - change the `root` to point to the directory where your jekyll site is built
  - change the `index` to the index file of your jekyll site

### Run Docker Container
- to run the production server, use the `compose-prod.yml` file
  - ``docker-compose -f compose-prod.yml up``
  - you can now access your jekyll site at `http://localhost:8080`
  - container will automatically rebuild the site when changes are made to the jekyll site directory, wich will then be served by the nginx server

## Set Up SSL
For production sites, you may want to add SSL to your site. 
- Use a reverse proxy like `nginx` or `traefik` to handle SSL termination
- Use a service like `Let's Encrypt` to get free SSL certificates
  - `Let's Encrypt` provides a `certbot` tool that can be used to get SSL certificates for your domain


## Authentication
For production sites, you may want to add authentication to your site. There are several ways to do this, like using Basic Authentication with `nginx` or using a reverse proxy like `traefik` to handle authentication.

More advanced authentication methods like OAuth2 or JWT can be implemented using a reverse proxy like `traefik` or `nginx` with `Authentik` or similar services.

If you are using the jekyll-admin plugin, setting up authentication is especially important to secure access to the admin interface.

### Basic Authentication
- to add basic authentication to your site, you can use the `nginx` web server
- to set up basic authentication:
  - ensure a Password file creation utility such as such as `apache2-utils`, `httpd-tools` or `apache-tools` is installed
  - create a `.htpasswd` file using the `htpasswd` command
    - ``htpasswd -c .htpasswd username``
    - replace `username` with your desired username
    - you will be prompted to enter a password
- edit the `nginx.conf` file
  - uncomment the lines under `# Basic Authentication` and set the `auth_basic_user_file` to the path of your `.htpasswd` file

# Jekyll
## Jekyll Commands
- `jekyll new .` - create a new jekyll site in the current directory
- `jekyll build` - build the jekyll site
- `jekyll serve` - start the jekyll server
- `jekyll serve --watch` - start the jekyll server with watch mode
- `jekyll clean` - clean the jekyll site build directory

## Gem Commands
- `bundle install` - install dependencies
- `bundle update` - update dependencies
- `bundle exec jekyll serve` - start the jekyll server using the dependencies
- `gem install jekyll` - install jekyll
- `gem update jekyll` - update jekyll
- `bundle add jekyll` - add jekyll to the Gemfile

## Jekyll Docker Command Execution jekyll new .` - create a new jekyll site in the current directory
- `alias jekyll_exec='docker run --rm -v $(pwd)/jekyll:/srv/jekyll -v jekyll_bundle:/home/user/ marttasch/jekyll'` - create an alias for the jekyll docker command with a volume for the jekyll bundle
- `docker-compose exec jekyll /bin/bash` - start a bash shell in the jekyll container
